# RESPIRO
### Respiro è una piattaforma di allerta precoce per i virus respiratori in Europa. Le previsioni sono un ensemble a pesi uguali di quattro modelli: analoghi k-nearest-neighbour sulle stagioni passate, regressione quantilica con gradient boosting, un modello di gradient boosting diretto per orizzonte e il modello pre-addestrato Chronos usato zero-shot. I modelli sono addestrati congiuntamente sulle serie di sorveglianza in medicina generale di oltre 20 paesi europei (ERVISS e storico OMS), su una scala comune di intensità, e producono traiettorie probabilistiche da cui si ricavano i quantili. Per l'Italia usano i dati RespiVirNet pubblicati nel repository di Influcast.
