# CNR4Cast-SIR_EnKF
Modello epidemiologico meccanicistico SIR strutturato per classi di età, nel quale la trasmissione tra gruppi è descritta mediante una matrice di contatto sociale. I dati epidemiologici settimanali vengono assimilati sequenzialmente mediante un Ensemble Kalman Filter (EnKF), che aggiorna lo stato epidemico e parametri selezionati del modello. A ogni aggiornamento, un ensemble di traiettorie viene propagato nel futuro per produrre previsioni probabilistiche dell’incidenza influenzale a diversi orizzonti temporali. La distribuzione dell’ensemble viene utilizzata per quantificare l’incertezza predittiva. Le previsioni sono generate in modo prospettico: la previsione relativa a una determinata settimana utilizza esclusivamente i dati disponibili al momento in cui viene emessa.
